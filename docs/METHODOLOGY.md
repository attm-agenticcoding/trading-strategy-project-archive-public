# 研究方法与复现边界

## Crypto 观点

原始观察期是 2021-10-15 至快照日期，收录样本不完整。方向、持仓披露、条件判断、相对币对和背景评论分开；没有足够证据的记录不评分，不把卖出或平仓自动转换成反向信号。

固定期限情景以观点日期后一个 UTC 日的完整日收盘入场，在入场后 7/30/90/180 个日历日的收盘退出。long 收益为 `exit / entry - 1`，short 为其相反数，未计手续费、融资、滑点或借券成本。它是明确的简单方向情景；做空亏损可以超过初始名义资本。逐日路径的峰谷回撤以 `1 + 简单方向收益` 为净值，不假设保证金清算；当值为负时，回撤也可能低于 -100%。

任何缺失日价都不补值；入场日未上市不延后入场。期限尚未结束为 pending；资料不足或非可评分记录为 unavailable。交易场所与 USD、USDT、USDC、原生币对报价不能默认为可互换。相对币对不混入美元收益榜。

原期限核验只保留已有的 result 和 deadline，和固定期限收益分开。unscored/pending 不进入已判定样本正确率；不能以正收益替代原话目标命中。源码来源归属与原文审核在本次公开制作中没有重新执行。公开概述、来源链接和存量结果可供检查，原始抓取内容没有随附。

## 动量研究

已存指标包含不同起点、前一收盘／首日开盘和止损假设。固定止损以入场价为基准，跳空低开按低于阈值的开盘价成交，而不是保证按阈值成交。部分早期年份只有年度价格或区间边界，原始完整日内路径缺失；既有汇总的边界声明不能视为补齐数据。

`research.tax.settle_gain` 原样保留已审核的亏损结转核心：亏损只抵未来组合资本利得，不产生外部退税。它不包含全部税种、账户差异或个人税务事实。

公开副本没有完整原始价格面板、全部修订研究包或原始附件，因此不提供全历史回测一键重建。测试中的合成小样本只验证算法边界，绝不充当历史行情或原研究证据。

## 代码来源

公开行情抓取与日价校验代码从既有研究源码的明确白名单复制；不包含已下载响应。亏损结转函数从既有研究引擎单独提取。固定期限方向情景为既有计算逻辑的独立标准库实现，删除了对私有文件结构的依赖，保留日期、方向、缺失值和回撤口径。公开摘要生成和校验脚本是为本副本新写的工具，不是历史研究采集器。
