# 发布核查说明

本副本采用逐字段白名单建立公开数据，不使用“复制全部再屏蔽几段”的方法。正文只保留 436 条原创中文概述、来源链接、分类与有限的已存结果字段；没有 excerpt、原文正文、抓取 HTML、逐日路径或维护日志。动量部分仅公开六组假设回测指标及公开来源。

行情读取代码逐文件审核；独立情景与亏损结转函数有离线边界测试。公开测试还会检查全部 815 项已完成情景的入场日期、截止日和方向收益算术。测试不会访问行情接口，不会冒充重跑完整研究。

发布树只允许文档、JSON 和 Python 源码，没有工作流、图片、压缩包、分件、二进制表格或缓存。`PUBLIC_MANIFEST.json` 对除清单自身之外的每个公开文件登记字节数和 SHA-256；清单自身也接受内容扫描。

所有公开文件和新提交 metadata 都在上传前检查。新历史仅含一个根提交，发布身份使用通用维护者名称和 GitHub noreply，不使用本机身份。来源人物、公开账号与第三方仓库名属于公开来源信息。

自动规则只覆盖明确风险格式，人工检查用于核对字段语义、代码依赖和来源用途；不作绝对无遗漏保证。旧私有归档及其工作流继续独立保留，未在此副本执行或改变。
