# 公开范围

本副本从白名单重新组装，并从单个新根提交开始。它保留独立研究工具、原创中文观点概述、已存数值汇总、公开来源链接和方法说明。

没有带入：旧 Git 历史、个人姓名与设备信息、本机绝对路径、会话／项目／附件标识、操作记录、维护偏好、凭据、私密通知地址、第三方全文／转录／推文全集、旧压缩包／分片、损坏包、未解析二进制表格及未审查图片。公开作者名称与公开 GitHub 仓库账号属于来源或发布身份。

允许的文件路径和扩展名由 `scripts/check_public.py` 限定，校验清单覆盖整个公开树。检查会扫描文档、数据、代码和新提交元数据。它是发布前的具体核查，不是“绝对无敏感信息”的保证。

本仓库不运行自动工作流。建立这个公开副本不会停止任何已有私有仓库的 CI、扫描、通知或调度，也不会减少那些任务的分钟消耗。
